# FrontForge AI

**FrontForge AI** is a lightweight, local-first multi-agent system that generates complete, runnable React applications from plain text prompts. It runs entirely offline using open-source models via Ollama or `llama.cpp`—no cloud APIs, no costs, and no data leaks.

---

## Why FrontForge AI?

* **100% Local & Private:** Your prompts and generated code never leave your machine.
* **Zero API Fees:** Completely replaces costly cloud models (GPT-4/Claude) with local open-source models (Llama 3, Mistral, Qwen).
* **Consumer Hardware Optimized:** Specifically designed to run efficiently on standard laptops without a dedicated GPU.
* **Production-Ready Output:** Generates full React bundles including components, routing, styling, and mock data.
